# Web-технологии

Next.js, React, TypeScript и Tailwind CSS.

Идея общего продукта — «Планировщик студента». Техническое задание,
содержание всех лабораторных и чек-лист выполнения описаны в [TODO.md](TODO.md).

Сайт объединяет 10 лабораторных работ в единый отчёт. Выполнен этап 1:
главная, текущая версия планировщика, учебные данные и лабораторные 1–2
с самостоятельными HTML-демонстрациями и заполненными главами отчёта.
Лабораторные 3–10 пока запланированы.
Пункт «Зачёт» — итоговая аттестация, а не отдельная лабораторная.

## Запуск

Для приложения, генератора примеров и тестов нужен Node.js 22.18+; разработка
и проверка текущей версии выполнены на Node.js 24.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

- `/project` — текущая версия после ЛР 2: статическая таблица и учебная форма.
- `/labs/1` и `/labs/2` — выполненные работы с теорией, кодом и проверками.
- `/report` — общий отчёт, две главы заполнены, остальные пока содержат заглушки.

Форма ЛР 2 проверяет обязательные поля и открывает локальную страницу результата.
Задачи пока не добавляются и не сохраняются. JavaScript и хранение появятся на этапе 3.

## Команды

- `npm run dev` — сервер разработки.
- `npm run build` — сборка для публикации.
- `npm start` — запуск собранного проекта.
- `npm run lint` — проверка кода.
- `npm test` — проверки учебных данных и календарных границ.
- `npm run labs:generate -- 2026-09-13` — явно пересоздать HTML-снимки ЛР 1–2
  на указанную дату; при обычном запуске и сборке команда не выполняется.

## Заполнение лабораторной

Создайте модуль в `src/data/labs/` по образцу `lab01.ts`, заполните
`contribution`, `goal`, `task`, `theory`, `steps`, `result`, `checks`,
`conclusion` и `sources`. Подключите его в реестре `src/data/labs.ts`.
Статус `done` ставится после проверки демонстрации и заполнения отчёта.
Один компонент `LabReport` выводит эти данные на странице работы и в общем отчёте.

Для демонстрации укажите `demo: { src, title }`, например
`{ src: "/labs/03/index.html", title: "ЛР 3 — подключение CSS" }`.
`Demo` покажет страницу через iframe и добавит ссылку для отдельного открытия.
В следующих работах CSS и JavaScript размещаются рядом с HTML-примером;
обращения к DOM выполняются внутри демонстрации.

Фрагменты `sourceExamples` ссылаются на файл из разрешённого списка
`src/lib/lab-sources.ts` и секцию между комментариями
`<!-- example:название:start -->` и `<!-- example:название:end -->`.
Добавляя новый файл, расширьте список и тип `file` в модели работы.
Код читается на сервере при сборке из самого HTML, ручная копия в отчёте не нужна.

Учебные данные для последующих интерактивных работ создаёт `createDemoTasks(today)`:
даты рассчитываются относительно локального календарного дня.
HTML первых двух работ — зафиксированные снимки на 13.09.2026, а не живой календарь.
Чтобы намеренно пересоздать эти снимки, измените шаблоны генератора и запустите
`labs:generate` с датой. Команда перезаписывает файлы ЛР 1–2; новые этапы
разрабатываются в отдельных папках и не требуют её запуска.

При добавлении новой записи в `labs` список, навигация, маршрут и общий отчёт
обновляются автоматически. Отдельная папка маршрута на каждую работу не нужна.

## Единый отчёт

Откройте `/report` и нажмите «Печать / сохранить PDF». В диалоге браузера
можно выбрать сохранение в PDF. При печати скрывается навигация,
а каждая лабораторная начинается с новой страницы. Интерактивные демонстрации
остаются в веб-версии; для печатной версии опишите результаты в `result`.

Данные автора, группы и преподавателя пока не указаны — их нужно заполнить
в `src/data/report.ts`. Титульный лист и оформление необходимо уточнить
по требованиям преподавателя. После заполнения работ удалите пометку о черновике.

## Хранение данных

На этапе 1 используются статические примеры. Для ЛР 10 запланирован `localStorage`.
База данных и Supabase сейчас не подключаются; к ним можно вернуться, если
понадобятся учётные записи и доступ к задачам с разных устройств.

## Проверка этапа 1

Пройдены ESLint, production-сборка, тесты фабрики задач и браузерная проверка
в Chromium: маршруты, якоря, обязательные поля, ограничение длины, сброс,
локальная отправка формы, iframe и ширины 360/768/1440 px.
Проверены состав отчёта, скрытие демонстраций при печати и создание PDF.
