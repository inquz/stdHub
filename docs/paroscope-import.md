# Импорт расписания: требования для JavaScript-лаб

Сценарий: выбрать Excel → верхняя / нижняя / обе недели → скачать PNG всей недели.
В CSS-лабах показывается статический пример. Настоящий разбор файла и создание PNG
ещё не реализованы.

Для каждого занятия извлекать отдельно:

- день недели и номер пары;
- вариант недели (`upper`, `lower`, `both`);
- название предмета и тип занятия;
- аудиторию;
- **преподавателя**: фамилия, инициалы и должность ровно как в исходнике.

Образец: `КИ-24.xls`, осень 2026–2027. В нём преподаватели записаны в столбце L,
в строках с аудиторией/дополнительными группами, а не обязательно в строке
названия предмета. Сопоставлять преподавателя с блоком занятия и его половиной
недели с учётом объединённых ячеек. Не переносить преподавателя из предыдущей
пары в пустой блок. Время звонков и полные имена по инициалам не выдумывать.

Общие пары показывать один раз в режиме «Обе» и в каждом отдельном режиме.
Преподаватель должен оставаться в карточке и на экспортируемой картинке,
в том числе в компактном виде. Совпадение названий предметов недостаточно
для объединения занятий: учитывать также тип занятия, аудиторию и преподавателя.

Контрольные примеры из файла:

- Понедельник, пара 2: верхняя — психология, доц. Павлова Е.В.; нижняя —
  веб-технологии, доц. Завадская Т.В.
- Понедельник, пара 3: обе недели — операционные системы, доц. Чередникова О.Ю.
- Вторник, пара 4: окно, преподавателя нет.
- Четверг, пара 3: верхняя — цифровая схемотехника, ст.пр. Максименко Н.С.;
  нижняя — веб-технологии, асс. Шубников В.С.

В образце 20 непустых блоков занятий с преподавателями (общий блок считается
один раз). Статические данные для ЛР 5–6 находятся в
`scripts/data/teachers-example.mjs`. Формат других Excel ещё не проверен.
