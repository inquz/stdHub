Небольшой эксперимент

Один текст, три источника цвета

Основной дизайн хранится в styles.css. Блок style и атрибут style меняют только образцы ниже.

Внешний файл

Цвет из styles.css: #C6B6EF

Блок style

Позднее правило: #F4BF9E

Атрибут style

Стиль на элементе: #98D9B0

Для .cascade-sample внешний файл и блок style задают обычные авторские правила без слоёв, с одинаковой специфичностью. Блок style подключён позже и меняет цвет на персиковый. В третьем образце обычный inline-стиль перекрывает эти правила. Здесь нет !important: это результат именно данного примера, а не безусловный порядок приоритетов.
